Центровка выходов усилителей БВ-24

← ВУАП-1 (общее меню)

Содержание операций / Технические требования / Работы при отклонениях от ТТ

Содержание операций

Замерить выходное напряжение усилителей блока БВ-24, для чего подключить тестер (диапазон измерения постоянного напряжения 100 мВ) к следующим контактам контрольного разъёма САУ РМ Ш3, расположенного в радиоотсеке:

• к контактам 16 и 6 — для сигнала Z (боковое перемещение);
• к контактам 17 и 6 — для сигнала Yз (γзад, регулировка крутизны выходного сигнала заданного угла крена);
• к контактам 18 и 6 — для сигнала X (продольное перемещение);
• к контактам 19 и 6 — для сигнала Uз (ϑзад, регулировка крутизны выходного сигнала заданного угла тангажа).
Если надо «слово в слово» — просто замени текст внутри этого блока.

Технические требования (ТТ)

Напряжение, снимаемое с контактов разъёма РМ Ш3 по сигналам Z, Yз, X, Uз, должно быть в пределах:

0 … 50 мВ
Допуск одинаковый для всех четырёх сигналов.

Работы, выполняемые при отклонениях от ТТ

Вращая ось подстроечного резистора блока БВ-24, добиться, чтобы величина напряжения по тестеру была в пределах 0 … 50 мВ:

• R38 — для сигнала Z (контакты 16/6);
• R39 — для сигнала Yз (γзад, контакты 17/6);
• R40 — для сигнала X (контакты 18/6);
• R41 — для сигнала Uз (ϑзад, контакты 19/6).
Если у тебя в технологии другое соответствие «Rxx ↔ сигнал» — поправь тут.

Калькулятор: центровка выходов усилителей БВ-24

Вводи измеренные значения (мВ) для 4 сигналов по разъёму РМ Ш3:
Z — 16/6 (боковое перемещение), Yз — 17/6 (γзад крен), X — 18/6 (продольное перемещение), Uз — 19/6 (ϑзад тангаж).
Допуск для каждого: 0 … 50 мВ.
ОЖИДАЕТ
Введите значения всех четырёх сигналов (мВ) и нажмите «Проверить».
