Пункт 5.8. Проверка передаточного числа по высоте

АП-34Б | МИ-8 | Таблица 3
Перед проверкой
Перед проверкой необходимо выписать из паспорта на АП-34Б, АП-34Б серия 2 §9 "Заметки по эксплуатации" крутизну корректора высоты Ккв (В/м).

В случае отсутствия в паспорте этой записи, необходимо произвести замер крутизны корректора высоты.
Пример: Нам надо задать напряжение по вольтметру "3" для 8 метров:
8 x 0,16 = 1,28 В

Где 0,16 — это крутизна характеристики по высоте, взято из паспорта КВ-11 или рассчитано самим.

Расчёт крутизны: Напряжение получили 16 В по вольтметру "3" при 100 м:
16 : 100 = 0,16 В/м
** Пример проверки:
50 x 0,16 / 1,28 = 6,25
- где 50 — значение полученное по вольтметру "3"
- где 0,16 — крутизна (Ккв)
- где 1,28 — напряжение для высоты 8 метров

Иногда фигурирует 1,44 В для высоты 7-8 м (при Ккв=0,18)

Ккв = U H [В/м]

H — заданное разряжение в метрах высоты
